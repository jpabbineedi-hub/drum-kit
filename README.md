# Drum Kit 🥁

A browser-based **Drum Kit** built using HTML, CSS, and JavaScript.

The project allows you to play different drum sounds by either clicking the drum buttons or using the corresponding keys on your keyboard.

## 🥁 How to Play

You can play the drums in two ways:

### Using the Mouse

Click on any of the drum buttons to play its corresponding sound.

### Using the Keyboard

Use the following keys:

* **W** → Tom 1
* **A** → Tom 2
* **S** → Tom 3
* **D** → Tom 4
* **J** → Bass Drum
* **K** → Snare
* **L** → Crash

## 🛠️ Technologies Used

* **HTML** – Structure of the drum kit
* **CSS** – Styling, layout, and button animations
* **JavaScript** – Handling keyboard input, mouse clicks, sounds, and animations

## ✨ Features

* Interactive drum buttons

* Responsive interaction through mouse and keyboard

## 🚀 Running the Project

You can play the Drum Kit by opening `index.html` in a web browser.

You can also clone the repository and run it locally:

```bash
git clone https://github.com/jpabbineedi-hub/drum-kit.git
```

Then open `index.html` in your browser.
